# BELLA. — experiencia web interactiva

Proyecto web estático inspirado en la investigación sobre la influencia de los estándares de belleza contemporáneos en la construcción de la identidad y el bienestar integral de las alumnas de secundaria del Colegio Apostólico San José, 2026.

## Cómo abrir
1. Descomprimí el ZIP.
2. Abrí `index.html` en Chrome, Edge o Firefox.
3. No requiere instalación ni servidor.

## Estructura
- `index.html` — estructura de la experiencia.
- `styles.css` — estética, responsive y paleta.
- `script.js` — feed, revelación de imágenes, estadísticas animadas, mapa de influencias, clasificación y muro de mensajes.
- `assets/` — carpeta preparada para imágenes o recursos futuros.

## Datos incorporados
La web utiliza los resultados presentados en la investigación: muestra de 77 alumnas y los porcentajes de los apartados de resultados incluidos en el material entregado.

## Personalización
Para cambiar textos, publicaciones o preguntas, editá las variables y bloques correspondientes en `script.js` y `index.html`.
